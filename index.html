ABOUT THIS PROJECT

Built to make everyday tasks easier.

The My Codelab Todo App is a frontend project created to demonstrate practical web development skills through a useful, interactive productivity tool.

It combines a clean interface with task management, filtering, progress tracking, and browser-based storage. Your tasks stay on your device in the same browser.
